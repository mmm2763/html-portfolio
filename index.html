HTML Text Formating Tags

Bold

Example: This is text that is in bold.

The b tag allows for a text to appear in bold


Italic

Example: This is text that is in italic.

The i tag allows for the text to appear in italic.


Underlined

Example: This is text that is underlined

The u tag underlines a text.


Strikethrough

Example: This is text that has a strikethrough

The s tag creates a strike through a piece of text.


Subscript

Subscript Text: h20

The sub tag create a subscript. In this case, the 2 is written in subscript


Superscript

Superscript Text: x2

The sup tag creates a superscript. In this case, the 2 is written in superscript


Line Break

Example:

The br tag create a break in text. In this case, there is a break create between the words "is" and "a".
